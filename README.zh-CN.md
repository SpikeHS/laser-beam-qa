# Laser Beam QA：开源光学质量测试与分析算法

本项目从中国科学院物理研究所 N09 实验室的激光器表征需求中发展而来，
提供可复用的光学质量测试与分析算法。当前聚焦**激光光束的强度分布与传播特性**，
将模斑图像和轴向扫描结果转化为具有明确单位、可检查的定量指标。
维护者为 Sen Hu（SpikeHS），采用 MIT 许可证。

## 现有算法与输出

| 分析任务 | 算法与结果 |
| --- | --- |
| 光束位置与形状 | 强度加权质心、椭圆几何参数、主轴方向 |
| 光束宽度 | D4σ 二阶矩直径、剖面 FWHM，结合像素尺寸校准 |
| 传播与发散 | 高斯束包络扫描拟合、独立的远场线性拟合接口 |
| 测量质量 | 图像质量检查、可配置的结果判据 |
| 算法验证 | 已知参数的合成光束、数值回归与端到端测试 |

算法位于 [`packages/lbqa_analysis`](packages/lbqa_analysis)，带单位的数据结构位于
[`packages/lbqa_contracts`](packages/lbqa_contracts)。研究者可以将自己的校准数据接入分析接口。

## 可复现的模拟测试

模拟采集与 z 扫描提供完整的参考工作流，无需相机、电动位移台或厂商 SDK 即可运行，
便于检查算法、拟合参数与输出报告。

安装和运行命令见 [英文首页](README.md)。运行后打开 `runs` 下的 HTML 报告，
并检查 CSV/JSON 结果与配置快照。所有随仓库提供的图像与案例均为合成数据。

## 适用范围与后续方向

当前范围不包含波前检测或成像系统 MTF 分析。该版本不包含厂商 SDK、实际设备控制、
未完成的桌面界面或实验室测量数据。
示例校准为名义参数。模拟扫描采用高斯束包络拟合；独立的远场线性拟合接口
有不同的适用条件，不能混用其束腰含义。成功运行不会保留原始灰度采集帧。

后续将完善测量数据留存与跨工具样品追溯。数据充分后的预测模型属于未来规划，
现版本没有实现自主实验闭环。欢迎提供可公开或合成的回归案例。

详见[算法定义与限制](docs/methods.md)及[开发路线](ROADMAP.md)。
