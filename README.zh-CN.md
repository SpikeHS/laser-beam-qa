# 激光模斑分析与模拟扫描

本项目从 N09 实验室的激光器表征需求中发展而来。首个公开版本提供可独立
运行的分析与模拟核心，包含 D4σ、FWHM、质心、椭圆参数、模拟扫描和报告。
维护者为 Sen Hu（SpikeHS），代码采用 MIT 许可证。

安装和运行命令见 [英文首页](README.md)。运行后打开 `runs` 下的 HTML 报告，
并检查 CSV/JSON 结果与配置快照。所有随仓库提供的图像与案例均为合成数据。

该版本不包含厂商 SDK、实际设备控制、未完成的桌面界面或实验室测量数据。
示例校准为名义参数。模拟扫描采用高斯束包络拟合；独立的远场线性拟合接口
有不同的适用条件，不能混用其束腰含义。成功运行不会保留原始灰度采集帧。

后续将完善测量数据留存与跨工具样品追溯。数据充分后的预测模型属于未来规划，
现版本没有实现自主实验闭环。欢迎提供可公开或合成的回归案例。
