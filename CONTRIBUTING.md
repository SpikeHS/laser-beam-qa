# Contributing

Open an issue with a reproducible example, units, expected behavior and the
version used. Synthetic inputs are preferred. Run the test suite before a pull
request. Changes to scientific methods need a documented definition and a
regression example with known expected behavior.

Keep physical units explicit. Separate raw inputs from visualization and
derived results. Do not add local paths, instrument credentials, vendor SDKs,
or unpublished laboratory measurements. Preserve third-party notices when
introducing external code. Contributions are distributed under the project's
MIT license.

The maintainer reviews changes before release. Proposed features and predictive
modeling milestones are tracked in ROADMAP.md; they are not current capabilities.
