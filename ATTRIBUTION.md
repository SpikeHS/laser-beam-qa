# Authorship and scope

Maintainer: Sen Hu ([SpikeHS](https://github.com/SpikeHS)).

The tools grew from laboratory research requirements and were developed by
Sen Hu with OpenAI Codex assistance. Scientific requirements came from research
colleagues; maintenance, validation and release decisions remain human
responsibilities. This is a maintainer-led project, not an official institutional
software release or a claim of institutional endorsement.

This public distribution contains selected, prepared source code and synthetic
examples. It does not distribute vendor SDKs, device drivers or laboratory
measurement datasets. Python/browser dependencies retain their own licenses.
